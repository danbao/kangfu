# 康复训练每日打卡工作台

一个柔和、简约的康复训练每日打卡微信小程序：左侧管理训练项目，右侧日期矩阵打卡，顶部统计完成情况，支持备注、休息日标记与月度报告导出。

## 功能

- **左右分栏工作台**：左侧训练项目列表，右侧日期打卡矩阵，行严格对齐
- **项目管理**：新增、编辑、删除训练项目，长按拖拽调整顺序
- **打卡矩阵**：点击单元格打勾/取消，完成格浅粉色标记，横向滚动浏览日期
- **统计**：当日完成数与完成率，支持周/月视图切换，点击日期表头切换焦点
- **备注与休息日**：长按日期表头（或点铅笔角标）记录身体感受、标记休息日
- **月度报告**：一键生成当月打卡热力图，可保存到相册或分享给医生
- **自动保存**：所有数据本地持久化（微信本地存储）

## 导入与运行

1. 打开 **微信开发者工具**，选择「导入项目」
2. 目录选择本文件夹（`kangfu`）
3. **AppID**：填写你自己的小程序 AppID；如仅测试，可勾选「测试号」（`project.config.json` 中已用 `touristappid` 占位，请替换）
4. 点击导入，编译预览

> 需微信开发者工具稳定版，基础库建议 2.33.0 及以上。

## 数据说明

- 打卡数据存储在微信本地（`wx.setStorageSync`），不联网、不上传
- 卸载小程序、清理微信缓存或更换设备会导致数据丢失，请定期使用「月度报告」保存图片备份
- 完成率按项目创建日期计算，新增项目不会拉低其创建前的历史完成率

## 目录结构

```
kangfu/
├── app.js / app.json / app.wxss     # 全局入口与设计令牌
├── pages/workbench/                 # 工作台页面（核心）
├── components/                      # stats-bar / note-panel / report-panel
└── utils/                           # 常量/图标/日期/换算/存储/统计/报告
```

## 技术要点

- 左右行对齐：同源遍历 + 固定行高 + 同一垂直滚动上下文
- 拖拽排序：全屏 capture 层接管触摸 + JS 节流更新，杜绝事件断流
- 图标：内联单色线性 SVG（base64），柔和浅灰描边，跨平台一致
